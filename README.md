## Kafka deck

Contains the slides and demo I prepared for Kafka Session

## Setting up...

### Install the marp cli

```bash
npm install -g @marp-team/marp-cli
```

### Serve the Deck

```bash
$ marp -s ./
```

### Serve in Watch Mode

```bash
$ marp -w ./kafka.md
```

### Export the Deck

```bash
marp kafka.md -o converted.pdf --allow-local-files
```
